# Instagram投稿デザイン参考集（Claude Code Factory用）

このフォルダの画像は「見た目の参考」です。画像の文字・数値・受験実績は、そのまま正しい情報として流用しないでください。投稿の正確な文言は台本データから新たに組み立て、プログラムで日本語を描画してください。

## デザインパターン

- `01_dark_gold_hook.png`：黒地・金の輝き・赤い見出し・大きな立体文字。強いフック1件、危機感や注目喚起を狙う「1枚10秒リール」の主要案。
- `02_red_gold_ranking.png`：ランキング・箇条書き・キャラクター・数個のボックス。ひと目で概要をつかませ、保存につなげるリール案。
- `03_white_navy_infographic.png`：白地・紺赤の見出し・チェックリスト・小見出し。フィード向きの情報整理テンプレート。必要なら1枚リールにも。
- `04_warm_checklist.png`：淡色ベース・緑/赤アクセント・親しみやすいデフォルメ武将。行動促進のリールまたはフィードに。

## 絶対仕様

1. リール = **1080×1920pxの静止画像を1枚だけ表示した10秒のMP4**。スライド切替、アニメ、ズーム、パンは使わない。書き出しはH.264 / yuv420p、30fps、必要なら無音。
2. フィード = 1080×1350pxの画像、または同サイズ画像を複数枚使ったカルーセル。
3. 画像生成AIに日本語全文を描かせるのではなく、背景・飾り・イラスト素材と、正確な日本語のテキストレイヤーを分離する。日本語テキストの誤字、文字欠け、重なりを視覚検証する。
4. InstagramのUIと重なる範囲を考慮してリールの上下・右側に安全余白を確保する。重要な見出しやCTAを端に置かない。
5. 投稿ごとに `design_style` と `format` を設定できるようにし、`A/B/C/D` の選択、プレビュー、画像/動画の書き出しを可能にする。
6. 事実・偏差値・大学入試制度・合格率・ランキングには出典や集計条件を要求する。未確認の数値や実績を捏造しない。
7. 早稲田大学公式アカウントであるかのような誤認を生む表示を避ける。大学ロゴ・画像の使用権利を確認する。

## 実装の進め方

- 既存リポジトリの構造を読んでから、`design_references/` を参照する複数テンプレートを追加。
- 生成された台本からタイトル・補足・表/箇条書き・CTAの量を判定し、読みやすい情報量に調整。
- デザインごとの同一企画のサンプルプレビューを作成して目視確認できるようにする。
- SNS投稿前には人間による承認ステップを残す。

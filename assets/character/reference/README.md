# 参照画像フォルダ

ここに「ちび秀吉」の参照画像（PNG推奨、背景透過・全身）を置くと、
画像生成AIがそのデザインを元に5つの表情（喜ぶ・驚く・怒る・考える・解説する）を作ります。

- 何も置いていない場合: 初回の本番実行時に1枚目を自動生成し、`auto_reference.png` として保存します。
- APIキーが無い場合: プログラムで描いた仮のオリジナル素材（`assets/character/mock/`）を使います。

生成された表情は `assets/character/expressions/` に保存され、以後は毎回それを使い回します。
デザインを作り直したいときは `expressions/` 内の PNG を削除してから再実行してください。
自分で用意した表情画像を `expressions/happy.png` のように置けば、それが最優先で使われます。
